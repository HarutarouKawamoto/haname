# 席予約 API の概要

## 目的

喫茶こもれびの席を、電話ではなく Web から予約できるようにする。店主が一人で切り盛りしているため、予約の受付と確認に手を取られないことを優先する。

## できること

- 空いている枠を、席ごとに一覧する
- 枠を選んで予約する（人数は 1〜4 人）
- 予約を取り消す（前日の 20 時まで）

## できないこと

- 支払い。会計は店で行う
- 席の指定なしの予約。必ず席を選んでもらう

## 前提

- 営業は 8:00〜18:00。予約は 30 分刻みで、1 回 90 分
- 席は 7 つ。窓際 3、カウンター 2、奥のソファ 2
- 予約の時刻はすべて日本時間で扱う
