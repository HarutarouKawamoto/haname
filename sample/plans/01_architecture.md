# アーキテクチャ設計

## 永続化

> [!ANSWER] Q1
>

DBはイベントソーシングで永続化し、CQRSで読み取りモデルを分離する。読み取り側は非同期で更新される。書き込みはアグリゲート単位でトランザクション境界を張る。

- コマンドはハンドラ経由でアグリゲートに渡す
- イベントはOutboxパターンでブローカーに配送する
- 読み取りモデルはプロジェクタが再構築可能

## API

REST ではなく tRPC を採用する。型をクライアントと共有できるため、スキーマ駆動の手間が減る。

| 層 | 技術 |
|---|---|
| API | tRPC |
| DB | PostgreSQL |
